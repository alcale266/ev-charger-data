# 구미시 전기차 충전기 상태 수집

한국환경공단 공개 API의 현재 충전기 정보를 주기적으로 관측합니다. 개인 정보·팀원 정보·분석 결과는 수집하거나 게시하지 않습니다.

## 출처와 이용 조건

- 제공기관: 한국환경공단
- 공식 자료: https://www.data.go.kr/data/15076352/openapi.do
- API: https://apis.data.go.kr/B552584/EvCharger/getChargerInfo
- 공공누리 제1유형(출처표시). 이 데이터는 해당 기관의 제공값이며 실제 현장 상태를 보증하지 않습니다.

## 수집 방식

- 매시 07·17·27·37·47·57분 예약 실행. GitHub 사정에 따라 지연·누락될 수 있습니다.
- 경북(zcode=47) 전체 페이지를 조회한 뒤 주소에 구미시가 포함된 기록만 보관합니다.
- 최근 변경분만 주는 상태 API가 아니라 현재 정보 전체 페이지를 사용합니다.
- 페이지별 조회 시각(collected_at_kst)과 원본 갱신 시각(statUpdDt)을 구분합니다. 여러 페이지는 동일 순간의 원자적 스냅샷이 아닙니다.
- 한 번에 최대 6페이지, 한국시간 날짜별 최대 900회 요청하는 안전 제한이 있습니다. 포털의 실제 호출량도 확인해야 합니다.

## 파일

- data/latest_gumi.csv: 마지막으로 완전하게 수집한 구미 데이터. 엑셀에서 열 수 있습니다. 실패한 실행 때는 이전 성공 자료가 유지되므로 반드시 조회 시각도 확인하세요.
- data/latest_run.json: 가장 최근 실행 성공 여부, 시각, 행 수, 오류 종류.
- data/snapshots/날짜/*.json.gz: 실행별 메타데이터와 구미 기록. 압축 JSON이며 실패 시 부분 기록도 있으므로 metadata.complete=true인 자료를 구분하세요.
- data/request_budget.json: 이 수집기의 요청 횟수 기록. 다른 곳에서 같은 인증키로 호출한 횟수는 포함되지 않습니다.

## 중요한 한계

관측 사이의 짧은 충전은 놓칠 수 있습니다. API의 마지막 충전 시작·종료 값은 전체 충전 이력이 아닙니다. 장애·미확인·누락·오래된 상태를 자동으로 이용 가능으로 해석하면 안 됩니다. 이 수집기는 예측 정답이나 성능을 생성하지 않습니다.

## 관리

Actions → Collect Gumi charger snapshots에서 실행 성공·실패를 확인합니다. Run workflow로 수동 실행하고, More workflow actions → Disable workflow로 예약 수집을 중지할 수 있습니다.

인증키는 DATA_GO_KR_SERVICE_KEY라는 Actions secret에만 보관합니다. 키를 공개 코드·로그에 입력하지 마세요. 표준 ubuntu-latest 실행 환경을 사용하며 유료 서비스는 설정하지 않았습니다. 장기 운영 시 저장소 용량과 실패 기록을 점검하세요.
